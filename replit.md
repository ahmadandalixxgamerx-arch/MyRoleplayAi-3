# VelvetCore // EREBOS

## Overview
A high-end, immersive roleplay interface powered by Google's Gemini AI. Features include branching dialogue (swipes), character/memory management, and real-time translation.

## Project Structure
- `App.tsx`: Main application logic and UI.
- `components/`: Reusable UI components (Modals, Buttons, Viewers).
- `services/`: API integration services (Gemini, Translation).
- `constants.ts`: Default settings and mock data.
- `types.ts`: TypeScript interfaces for the project.
